# SEO: 301 the legacy en.carissues.co.il host to carissues.net

> **Redirect change.** This PR adds a new redirect: `en.carissues.co.il/*` → `carissues.net/*` (301). It doesn't touch robots.txt, sitemaps, the www→apex rule or canonicals on the real hosts.

Branch: `seo/2026-11-15-en-subdomain-301`. Apply with `git checkout -b seo/2026-11-15-en-subdomain-301 origin/main && git am seo-patches/2026-11-15-en-subdomain-301.patch`.

## What changed
- `src/lib/legacyHost.ts` (new): `legacyHostRedirect()` maps `en.carissues.co.il` (and `www.en.`) to the same path and query on `https://carissues.net`. `/ru` paths go to `https://carissues.co.il` instead, so there's only one hop.
- `src/middleware.ts`: this runs first, before the /embed, www and /ru rules, and returns a 301.
- `tests/legacyHost.test.mjs`: 4 tests. `npm test` passes 85/85, and `tsc` shows no new errors.

The Worker route `en.carissues.co.il/*` stays in `wrangler.toml` because it's needed to serve the redirect. The en host isn't in `EDGE_CACHE_HOSTS`, so cached HTML can't hide the redirect.

## Why
`en.carissues.co.il` is the old English host. It still returned full English pages with a 200 status and a canonical pointing to carissues.net. Google indexed them as a separate host anyway. Search Console, sc-domain:carissues.co.il:

| window | en.carissues.co.il URLs | impressions | clicks | avg pos |
|---|---|---|---|---|
| 2026-09-18 → 10-15 | 0 | 0 | 0 | – |
| 2026-10-16 → 11-12 | 335 | 1,151 | 2 | 42.3 |

These duplicates compete with the real carissues.net pages, for example `/cars/compare/honda/jazz/toyota/aygo` (31 impr) and `/cars/tesla/model-s` (45 impr). A 301 is a stronger signal than a canonical, and it moves those signals onto carissues.net.

## Metric to watch
- en.carissues.co.il impressions in GSC (sc-domain:carissues.co.il) should fall toward 0 within 2–4 weeks.
- carissues.net impressions and clicks for the same paths (sc-domain:carissues.net) should rise over 4–6 weeks.
- After deploy, check `curl -sI https://en.carissues.co.il/cars` → `301 location: https://carissues.net/cars`.
